# E-commerce UI Improvement

## 1. Giới thiệu
Cải tiến giao diện hiển thị thẻ sản phẩm trên website thương mại điện tử nhằm làm nổi bật giá bán, tỷ lệ giảm giá và tối ưu hiển thị responsive trên thiết bị di động.

## 2. Website tham khảo
- Tên website: Shopee / Tiki
- Khu vực đã khảo sát: Danh mục sản phẩm và Trang chủ

## 3. Chức năng
- Hiển thị danh sách thẻ sản phẩm dạng lưới (Grid).
- Hiển thị rõ giá khuyến mãi, giá gốc gạch ngang và nhãn giảm giá.
- Hỗ trợ co giãn responsive mượt mà từ màn hình máy tính (4 cột) sang điện thoại (2 cột).

## 4. Công nghệ
- HTML5
- CSS3 (Flexbox, CSS Grid, Media Queries)

## 5. Cách chạy
Mở trực tiếp file `index.html` bằng trình duyệt web Google Chrome.

## 6. Cải tiến đã thực hiện
Thẻ sản phẩm cũ có nút thao tác nhỏ và giá giảm chưa nổi bật. Bản thiết kế mới đã làm rõ mức giá nổi bật màu đỏ, bo tròn góc thẻ và cố định chiều cao tên sản phẩm tránh xô lệch layout.

## 7. Hỗ trợ từ AI
AI hỗ trợ gợi ý khung bố cục CSS Grid và media query cho điện thoại. Tôi đã tự tay kiểm tra, tinh chỉnh lại màu sắc nút bấm và khoảng cách lề.
